# Tutorial para Rodar o Projeto e Instalar Dependências

Este tutorial explica como **baixar o projeto via Git** e **instalar todas as dependências** necessárias usando o `requirements.txt`.

---

## 1. Pré-requisitos

Antes de começar, é necessario ter:

- [Python 3.10+](https://www.python.org/downloads/)
- [Git](https://git-scm.com/downloads)
- (Opcional) Um ambiente virtual para isolar as dependências

---

## 2. Clonando o projeto

Abra o terminal e rode o comando para clonar o repositório:

```bash
git clone https://github.com/Planctor/ProjetoIntegrador.git

Abra o terminal e rode os comandos para instalar o gerenciador de pacotes do Python e seus requerimentos:

pip install --upgrade pip
pip install -r requirements.txt
